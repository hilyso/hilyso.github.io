## 一、环境初始化

以下环境配置：`K8s-master`、`K8s-node01`、`K8s-node02`

### 0. 安装必要工具

`yum install -y wget curl tar vim socat conntrack ipset ipvsadm bash-completion`

### 1. 修改主机名

`hostnamectl set-hostname K8s-master`

### 2. 开启内核参数

```bash
modprobe br_netfilter overlay
cat <<EOF | sudo tee /etc/modules-load.d/k8s.conf
overlay
br_netfilter
EOF
```

### 3. 关闭交换分区

```bash
swapoff -a
sed -ri 's/.*swap.*/#&/' /etc/fstab
```

### 4. 关闭防火墙

```bash
systemctl stop firewalld iptables
systemctl disable firewalld iptables
```

### 5. 关闭 SELinux

```bash
setenforce 0
sed -i 's/SELINUX=enforcing/SELINUX=disabled/g' /etc/selinux/config
```

### 6. 开启时间同步

`systemctl enable chronyd --now`

### 7. 开启路由转发

```bash
cat >> /etc/sysctl.d/k8s.conf << EOF
net.ipv4.ip_forward = 1
net.bridge.bridge-nf-call-iptables = 1
net.bridge.bridge-nf-call-ip6tables = 1
EOF
```

### 8. SSH 免密登录

```bash
ssh-keygen
ssh-copy-id root@K8s-node01
ssh-copy-id root@K8s-node02
```

### 9. HOSTS 解析

```bash
cat >> /etc/hosts << EOF
192.168.100.115 K8s-master
192.168.100.116 K8s-node01
192.168.100.117 K8s-node02
EOF
```


## 二、使用自签证书

etcd 和 K8s 集群使用 **不同的 CA**。

### 1. 目录规划

```text
/etc/etcd/ssl/                # etcd 相关证书
/etc/kubernetes/ssl/          # k8s 组件证书（apiserver、controller-manager、scheduler、admin、front-proxy 等）
/etc/kubernetes/ssl/          # kubelet 证书
~/.kube/config                # kubectl 使用的 kubeconfig（admin 证书生成）
/etc/kubernetes/config/       # 各组件配置文件、kubeconfig（*.kubeconfig）
```


## 创建 CA

etcd  和 k8s 需要分别创建不同的 CA
cfssl 工具集可以快速创建所需证书

### 1. etcd CA

` cfssl gencert -initca ca-csr.json | cfssljson -bare ca `

``` bash
cat > ca-config.json <<EOF
{
  "signing": {
    "default": {
      "expiry": "87600h"
    },
    "profiles": {
      "server": {
        "expiry": "87600h",
        "usages": ["signing","key encipherment","server auth"]
      },
      "client": {
        "expiry": "87600h",
        "usages": ["signing","key encipherment","client auth"]
      },
      "peer": {
        "expiry": "87600h",
        "usages": ["signing","key encipherment","server auth","client auth"]
      }
    }
  }
}
EOF
```

``` bash
cat > ca-csr.json <<EOF
{
  "CN": "etcd-ca",
  "key": {"algo": "rsa", "size": 2048},
  "names": [
    {"C": "CN", "ST": "Hangzhou", "L": "Hangzhou", "O": "etcd", "OU": "etcd"}
  ]
}
EOF
```
